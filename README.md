# סינון נטפרי ל-Google Drive

## התקנה ועדכון
1. הורד ZIP דרך **Code → Download ZIP** וחלץ אותו.
2. פתח Chrome בכתובת `chrome://extensions`.
3. אם התוסף כבר מותקן, לחץ על סמל הרענון שלו (Reload).
4. פתח או רענן את Google Drive.

## שימוש
- התוסף אוסף פריטים מהתיקייה הנוכחית, כולל פריטים נוספים שנטענים בגלילה.
- לכל פריט יוצג מצב: **נפתח**, **נחסם**, או **לא נבדק**.
- חלונית ההתקדמות מציגה ספירה ומאפשרת לעצור את הסריקה.
- ניתן להפעיל ולכבות את הסימון בחלונית התוסף.

## מגבלות חשובות
- ללא Google Drive API והרשאת OAuth, התוסף יכול לסרוק את התיקייה הנוכחית שהממשק מציג. הוא אינו יכול להבטיח סריקה אוטומטית של כל התיקיות ותתי-התיקיות בחשבון.
- "נפתח" פירושו שהדף נטען בדפדפן ונראה כתוכן Drive/Docs; אין בכך הבטחה שכל תוכן הקובץ נגיש או שניתן להורידו.
- "נחסם" מוצג רק כאשר זוהתה הפניה לעמוד חסימה מוכר של נטפרי או הודעת חסימה מזוהה.
- כל תוצאה שלא ניתן לאמת תסומן "לא נבדק". אין עקיפת חסימות.
- במהלך הבדיקה נפתחות לשוניות רקע זמניות ונסגרות בסיום כל בדיקה.

# סינון נטפרי ל-Google Drive

## התקנה
1. לחץ על **Code → Download ZIP** והרץ חילוץ (Extract) במחשב.
2. פתח Chrome וגש לכתובת `chrome://extensions`.
3. הפעל **מצב מפתח**.
4. לחץ **טעינת תוסף שלא נארז** (Load unpacked).
5. בחר את התיקייה שחילצת.
6. פתח או רענן את Google Drive.

## שימוש
- פתח את חלונית התוסף כדי להפעיל/לכבות את הסימון.
- לחץ "סריקה מחדש" כדי לנסות שוב.
- פריט שהוביל בבדיקה לעמוד חסימה של נטפרי יסומן באפור.

## מגבלות חשובות
- זהו אבטיפוס ראשוני: הוא בודק עד 20 פריטים שכבר נטענו ברשימה הנוכחית, ולא סורק אוטומטית את כל החשבון או את כל התיקיות.
- בגלל אופן הפעולה של Google Drive ודרישות התחברות והרשאות, לעיתים לא ניתן לזהות חסימה בוודאות. התוסף אינו מציג "נגיש" כהבטחה.
- התוסף אינו עוקף חסימות של נטפרי; הוא רק מזהה הפניה גלויה לעמוד חסימה.
- בדיקות עשויות לפתוח לשוניות רקע קצרות שנסגרות אוטומטית.
